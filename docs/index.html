Getting started

ATLAS is a digital chain-of-custody platform for monitoring tracker locations, operational sites, access, and changes. Use the tabs in the top navigation to move between the main areas.

Demo onlyThis is a frontend demonstration. Invites, emails, authentication, exports, reports, live tracking and backend data synchronisation are not operational.
TrackersView live positions, device health and site membership.SitesCreate locations and manage circular geofences.UsersInvite people, assign roles and control seats.

Quick start

Open Trackers

Select a tracker card to focus its map marker and inspect the current location.

Create operational sites

Add your regular facilities and choose an appropriate geofence radius.

Invite your team

Assign the minimum role each person needs. Only active users consume seats.

Review activity

Use Logs and notifications to investigate changes, exports and security events.

Trackers

The Trackers page combines a searchable device list with a map. Each card shows its identifier, reported coordinates, GPS accuracy, site membership, last-seen time, battery, and cellular quality.

Demo onlyTracker positions are randomly generated. No live devices or tracking API are connected.

Finding a tracker

  • Search by tracker number, site, coordinates, battery percentage, signal label, or last-seen text.
  • Filter by site membership, low battery, weak signal, or devices not seen for 30 minutes.
  • Not at a site (in the field) isolates trackers that are outside every active geofence.
  • The map updates with the list, so hidden results are also removed from the map.

Using the map

  • Select a tracker card to fly to its marker and open the map popup.
  • Select Directions to open the reported coordinates in Google Maps.
  • Use Settings to change the demo city, number of generated trackers, tracker layer, site layer, or colour theme.
  • The accuracy circle represents the uncertainty around the reported GPS position.
Site membership: a tracker is shown at a site when its reported point falls inside that site's active circular geofence.

Device telemetry

Telemetry appears below the Directions link on each tracker card. Values are currently generated for the demo and are ready to be replaced by device API readings.

Cellular signal

Signal quality is calculated from both RSRP (received signal power) and RSRQ (received signal quality). ATLAS uses the weaker result so it does not overstate connectivity. Hover the signal indicator to see the underlying readings.

Sites and geofences

Sites represent operational locations such as hubs, depots, warehouses or customer premises. An active site has a circular geofence defined by a centre point and radius.

Demo onlySite changes are saved only in this browser. They are not sent to a database or shared with other users.

Add or edit a site

  1. Select Add site, or Edit on an existing site.
  2. Enter a name and optional address and postcode.
  3. Click the editor map or drag the marker to set the centre.
  4. Choose the radius in metres and save.

Use Enable or Disable to control whether a geofence participates in tracker membership. A confirmation toast appears after the status changes. Disabled sites remain configured but do not count as active locations.

Deleting sites: deletion removes the demo record from this browser. Prefer Disable when a location may be needed again.

Users and seats

The Users page controls organisation membership. The seat counter shows active users against the organisation's 10-seat demo licence.

Invite a user

  1. Select Invite user.
  2. Provide the person's name, email address and role.
  3. Select Send invite. The demo creates the invitation but does not send an email.
  4. When the future invitation service reports acceptance, the user automatically becomes Active if a seat is available.

Deletion is only offered for inactive users and requires confirmation. If all seats are assigned, disable another active user before enabling someone else.

Activity logs

Logs provide an organisation-wide audit trail. Entries can include successful and failed logins, invitations, user-role changes, site changes, tracker geofence events, and report exports.

Demo onlyLog entries are static examples. CSV and PDF buttons do not generate or download files.
  • Search by user, action or event detail.
  • Use the action dropdown to isolate logins, created records, changes, exports or security events.
  • User names and referenced trackers/sites link back to their relevant pages.
  • IP address and result fields help with security investigation.
  • CSV and PDF export controls are visible but are not connected in the frontend demo.

Notifications and account menu

The bell in the header opens recent operational and security notifications such as geofence entry/exit, failed logins, invitations and site changes. Select a notification to open the relevant page, or choose View all activity.

The profile image opens account shortcuts for My account, Account settings, My activity and Log out.

Demo onlyNotifications are examples and the count is random on refresh. Account settings and Log out do not work.

Reports and exports

Use the report button on a tracker card to select a start and end date/time for a tracker report. This is intended for historical movement and chain-of-custody reporting. The Logs page also provides CSV and PDF export controls for audit activity.

Demo onlyNo reports, CSV files or PDFs are generated. Export buttons demonstrate the intended workflow only.

Current demo limitations

  • Tracker positions, battery, cellular readings, last-seen times and notifications are generated demo data.
  • Site and user changes are stored in the current browser using local storage; they are not shared between browsers.
  • Invitation emails are not sent.
  • Authentication, account settings, logout, report files, log exports and billing are not connected.
  • Map tiles and Google Maps directions require internet access.
  • The role descriptions model intended permissions; production APIs must enforce every permission server-side.

Troubleshooting

Why is a tracker missing from the map?

Clear the tracker search and set the filter to All trackers. Confirm the tracker layer is enabled in Settings.

Why is a tracker not shown at a site?

The site's geofence must be active and the tracker coordinates must fall inside its radius. GPS accuracy can also place a reported point outside the expected boundary.

Why can’t I enable a user?

All 10 active seats may be assigned. Disable an active user to release a seat, then enable the required account.

How do I reset browser demo data?

Clear this site's local storage in your browser developer tools. Reloading alone preserves site and user changes.

Why did the notification count change?

The demo deliberately generates a new count on refresh. Production unread counts will persist.
